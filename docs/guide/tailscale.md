## 连接 Cage 与本机

左侧栏的「Tailscale」位于「浏览器」下方。它为当前 Cage 环境提供独立的 Tailscale 设备身份，登录状态保存在客机磁盘中。本机也需要安装 Tailscale，并加入同一网络。

启动 Cage 环境后打开此面板。Debian 环境首次使用时点击「安装 Tailscale」；macOS、Windows 环境的组件随应用提供，已有环境可按面板提示更新环境组件。点击「连接 Tailscale」，在 Cage 浏览器打开的官方页面完成授权。返回面板即可查看连接状态、Cage 私网地址和其他设备。网络启用设备审批时，还需由该网络的管理员批准设备。

当前开发构建已通过隔离私网中的双向 SSH、SFTP、端口转发和身份保留验证。真实 Tailscale 账号授权、安装环境与本机的实际双向连接，以及三类客机暂停后的断线仍待验收。公开安装包是否包含此入口，以对应发行说明为准。

## 从本机连接 Cage

在 Tailscale 面板的「本机连接 Cage」中粘贴本机 SSH 公钥并点击「添加公钥」。公钥通常位于本机的 `~/.ssh/id_ed25519.pub`；私钥保留在本机。面板接受一条公钥，不接受私钥或带有限制选项的 `authorized_keys` 条目。

连接成功后，面板显示实际客机用户名和私网地址，例如：

```sh
ssh cage@100.88.2.3
```

在本机终端运行复制的命令。首次连接按 SSH 提示核对并保存服务端指纹。登录后获得当前 Cage 客机普通用户的权限，可使用交互终端、远程命令、SFTP 和 SSH 本地端口转发。SSH 服务仅在 Tailscale 网络监听，不开放主机公网或局域网端口。移除公钥会拒绝该密钥的新连接；断开 Tailscale 可结束已有私网连接。

## 从 Cage 连接本机

本机须开启操作系统的远程登录或 SSH 服务，并允许相应的 Tailscale 连接。在面板的设备列表找到本机，复制命令，将「本机用户名」替换为实际用户名，然后在 Cage 终端运行：

```sh
ssh 本机用户名@100.88.2.4
```

登录使用本机 SSH 服务支持的密码或密钥认证。Cage 不会导入本机私钥。通过 Tailscale 登录本身不会自动授予本机 SSH 权限。

Cage 会为已发现的私网设备维护客机 OpenSSH 配置，普通 `ssh`、SFTP 和使用 OpenSSH 的工具可按设备私网 IPv4、完整名称或短名称连接。这里使用标准 SSH 的认证方式；Tailscale 管理台的专用「Tailscale SSH」身份认证与这项公钥服务分别配置。

## 断开、退出与数据保留

「断开连接」结束私网连接，保留登录状态、公钥和 SSH 服务端身份。重新连接沿用原设备。「退出登录」撤销当前登录，下次连接需要浏览器重新授权；已添加的 SSH 公钥保留。关闭面板不会断开连接。

私网外层通信继续经过 Cage 的受控出口。公网 UDP 受限时，Tailscale 使用中继传输。暂停 Cage 外网、代理中断、环境停止或后台退出会影响私网连接。保留环境运行时，后台任务与私网按环境生命周期继续；重新启动会恢复已启用的 Tailscale 身份。

Tailscale 的网络访问规则仍决定设备间哪些连接可达。此功能提供 SSH 私网访问，不修改 Cage 的公网代理、系统 DNS、子网路由或出口节点设置。SSH 连接到本机后，命令在本机执行，其权限和网络行为由本机管理。
